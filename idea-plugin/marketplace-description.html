Metro adds IDE support for Metro, a compile-time dependency injection framework for Kotlin.

Explore and navigate your dependency graph directly from the editor:

  • Jump between injection sites and the bindings that provide them.
  • See provider, consumer, and graph relationships through gutter icons and Code Vision.
  • Show resolved implementations and multibinding counts as inline hints.
  • Browse graphs, scopes, contributions, and unused bindings in the Metro tool window.
  • Validate graphs on demand and follow missing-binding traces back to source.
  • Use Metro-aware Find Usages across source and compiled dependencies.
  • Add @Inject and contribution annotations with intention actions.

The plugin reads the Metro compiler configuration used by your project. It requires K2 and a project configured to use Metro.

This release is currently in early access preview. Please report problems and feature requests on GitHub.
